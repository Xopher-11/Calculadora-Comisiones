## Calculadora de Comisiones de Ventas 

## Objetivo
Este es un proyecto donde hice una página web que ayuda a los vendedores a calcular cuánto van a ganar de comisión al mes. Es una herramienta para que todo sea más claro y fácil para ellos.

## Funcionamiento del cálculo
La página sigue estas reglas del negocio:
1. Se ponen las Ventas Totales.
2. Se restan los Descuentos.
3. Al resultado se le aplica el porcentaje según el país:
   * India: 10% 
   * Estados Unidos (US): 15% 
   * Reino Unido (UK): 12%
   * Canadá (CA): 11% 
   * México (MX): 9% 

## Organización de la app
Para que el código esté ordenado, lo dividí así:
* Presentación: Es lo que el usuario ve y donde pone los datos.
* Lógica: Son las funciones que hacen las cuentas matemáticas.
* Datos: Donde están guardados los porcentajes de cada país.
