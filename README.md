## Calculadora de Comisiones de Ventas 

## Objetivo
[cite_start]Este es un proyecto donde hice una página web que ayuda a los vendedores a calcular cuánto van a ganar de comisión al mes[cite: 3]. [cite_start]Es una herramienta para que todo sea más claro y fácil para ellos[cite: 4].

## Funcionamiento del cálculo
[cite_start]La página sigue estas reglas del negocio[cite: 12]:
1. [cite_start]Se ponen las **Ventas Totales**[cite: 9].
2. [cite_start]Se restan los **Descuentos**[cite: 10].
3. [cite_start]Al resultado se le aplica el porcentaje según el país[cite: 11]:
   * [cite_start]**India:** 10% [cite: 13]
   * [cite_start]**Estados Unidos (US):** 15% [cite: 14]
   * [cite_start]**Reino Unido (UK):** 12% [cite: 15]
   * [cite_start]**Canadá (CA):** 11% [cite: 16]
   * [cite_start]**México (MX):** 9% [cite: 17]

## Organización de la app
[cite_start]Para que el código esté ordenado, lo dividí así[cite: 18]:
* **Presentación:** Es lo que el usuario ve y donde pone los datos (HTML y CSS).
* **Lógica:** Son las funciones que hacen las cuentas matemáticas (JavaScript).
* **Datos:** Donde están guardados los porcentajes de cada país.
